### Hi, I'm Rasheed 👋

**Librarian · Web developer · UX designer.** I build accessible information experiences for people and research.

I'm an **MSLIS candidate at the University of Illinois Urbana-Champaign** (expected May 2027), specialising in STEM librarianship, digital accessibility and user experience. Before graduate school I spent years as a web developer and UI/UX designer: I built client websites in Lagos and designed product interfaces for a Canadian technology team.

- 🔎 **Researching:** Boolean searching inside AI-enhanced academic databases (Grainger Engineering Library, UIUC).
- 🏛 **Working:** Pre-Professional Graduate Assistant at the Grainger Engineering Library. My work there covers reference, information literacy instruction and accessibility.
- 🌍 **Building:** small web tools that test how people search, including **NaijaTalk**, a chat assistant that answers in Yoruba, Igbo and Hausa.
- 🏅 **Recognised:** HSLI Jira Scholarship, 2026–2027.
